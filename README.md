# Aura-UI: Interfaz Adaptativa Basada en Señales Proxys de Frustración
Sistema que detecta el estado emocional del usuario (frustración, concentración, confusión) a partir de señales como el comportamiento del cursor, la velocidad de escritura o la cámara web (expresión facial), y adapta la interfaz en respuesta. Aplica los conceptos de IHM y computación afectiva.
